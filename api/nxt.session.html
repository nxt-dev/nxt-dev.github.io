execute_graph(filepath, start=None, parameters=None, context=None)[source]

Execute the graph at the given file path. Optionally at given start. You may provided parameters to the parameter arg. The data should be formatted as follows:

{
    '/node.attr': 'New value!',
    '/another.count: 5
}

If the node does not exist an error will be logged but the execution will continue. If the attr does not exist (but the node does) it will be created.

Parameters

  • filepath (str) – Path to the graph file.

  • start (str or int) – Path to the node to begin execution from OR int of start node index

  • parameters (dict) – Dict where key is attr path and value is new attr value.

  • context (str) – Optional name of remote context to execute graph in, if none is passed the graph is executed in this interpreter.

Returns

a runtime CompLayer.
